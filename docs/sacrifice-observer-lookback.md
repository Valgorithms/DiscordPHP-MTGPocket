# Sacrifice-specific observer lookback

Mayhem Devil's sacrifice callback previously collected live battlefield objects for each individual move. A source sacrificed early could miss later sacrifices in the same selected group; movement also reset a stolen source's controller and its incarnation before the callback. Sixteen paid-Barter cases reproduced missing triggers before this fix.

`Game::sacrifice()` now uses the selected group's pre-event observer registry, or a fresh cloned registry for an ordinary single sacrifice. `DeathObserverBatch` retains the selected objects' static battlefield definitions and current creature status before any selected move. Sacrifice dispatch uses that context and each observer's old face, controller and incarnation. Shared once-per-turn marks are retained and copied back to a surviving incarnation. This reuses the existing synchronous boundary; it does not add a second saved state or event queue.

A sacrifice is distinct from a creature death: the callback still runs when the existing `exileIfDies` replacement sends a sacrificed permanent to exile. Only actual deaths reach death observers. Destroying, exiling or bouncing a permanent directly never invokes the sacrifice callback.

Paid Barter in Blood tests cover both active players, both former controllers, both insertion orders, four targets/independent damage abilities, burial replaced by exile, and JSON replay before resolution and while choosing targets. Synthetic tests cover own/opponent/another/token/nontoken/type filters, transformed and animated context, transformed and face-down observers, a single self-sacrifice cost, surviving once-per-turn marks across two groups, and non-sacrifice negative controls. These supporting fixtures certify no additional corpus cards.

The forty focused cases pass 804 assertions; 221 adjacent cases pass 2,948 assertions. Three changed PHP files pass Pint. Full-suite and exact-head matrix evidence will be recorded before merge.

No parser, saved schema, environment variable or Discord UI contract changes. `env.example` needs no additions. Broader sacrifice-cost choices, continuous keyword/power/condition snapshots, replacement ordering, one-or-more event identity and general APNAP choices remain separate. This is scoped evidence for Mayhem Devil, not whole-card or newest-printing certification. Recognition remains 11,282 of 28,729 names; whole-card certificates remain zero. No imported-data gameplay, bot/Gaia startup, import, build, deployment or restart is performed.
