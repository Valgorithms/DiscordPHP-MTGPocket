# Emerge and transformed mana value

A transformed Huntmaster of the Fells has front-face mana value four, but the existing Emerge path read its visible back's absent cost as zero. Paid Wretched Gryff could be rejected for insufficient mana even when its `{5}{U}` Emerge cost should be reduced to `{1}{U}`; with extra mana and a competing two-value creature, the existing automatic selection could sacrifice the wrong creature. Both the discount and that selection now use the existing `battlefieldManaValue()` helper. [Wizards' rules notes](https://magic.wizards.com/en/news/feature/eldritch-moon-release-notes-2016-07-08) describe the front-face value and generic-only Emerge reduction.

The baseline on `2614b809714309e426abc6e2149b38b8d2b2ad07` reached 26 assertions across four cases: two insufficient-payment errors and two incorrect-sacrifice failures, covering both seats. The corrected expanded suite passes eight cases and 86 assertions: paid casts, automatic selection, cast-trigger draw and creature resolution after JSON restoration, face-down zero value, colored-cost requirement and atomic failed payments. Two later test-setup errors are retained: an assertion missed the second seat's normal draw, and a zero-land helper call unexpectedly created two Islands. Their corrected controls passed; neither is claimed as an engine defect.
