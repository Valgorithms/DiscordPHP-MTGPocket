# Departed-source power and toughness

The complete pinned KLD Marionette Master fixture reproduced 18 failures in 19 initial cases: counters and temporary power disappeared after departure, and a returned incarnation could substitute its power for the earlier source. The surviving-source control already passed. This milestone retains battlefield departure statistics by object incarnation and passes the resolving identity through nested effects. A surviving original permanent uses current statistics at resolution; a departed incarnation uses its own last-known statistics, even after the card returns or leaves again. Nonnegative quantities still clamp negative power to zero.

Selected movement groups capture power/toughness before their first move, alongside their existing definition/creature-status snapshots. Ordinary departures capture them just before movement clears counters, attachments and battlefield face. This is a bounded extension of the existing lookback boundary, not a complete continuous-effect, replacement, intervening-condition or APNAP model. Historical incarnation entries remain with the game object so an older queued ability cannot read a more recent departure. No generic engine service or new permanent inheritance layer is added.
