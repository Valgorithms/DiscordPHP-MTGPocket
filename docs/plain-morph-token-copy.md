# Copying a plain-morph face-down permanent

`FaceDownTokenCopyTest` pins the complete existing KTK Woolly Loxodon record, UUID `58ad74dd-6e19-5f96-9694-f2cee61a442e`, with normalized-LF SHA256 `03f2ef9e9d6cd60ce492c3c82929ee8ecfac874e1d88643b9180be86f99a20c1`. Its full text parses without unread clauses. This is scoped engine evidence, not whole-card certification or a certificate for a printed copy spell.

The baseline paid three mana to cast it face down, then paid one blue mana for the existing copy-token effect using a synthetic instant. All four source/creator controller combinations failed: the copy was the printed 6/7 rather than a 2/2. The baseline receipt identifies runtime `cc0a65f` with the test helper-name correction subsequently committed as `ffa96f9`; four cases made 64 assertions and failed in 0.747 seconds. Initial test-harness corrections also replaced invented modifier properties with the existing `untilEndOfTurn` representation and used the existing private movement route through reflection. These are distinct from the reproduced runtime defect.

The narrow fix selects the plain-morph face-down characteristics when the copy resolves (rules 707.2 and 708.2). It clears the source's synthetic turn-face-up action and placeholder name before token entry. The token enters face up as a nameless, colorless 2/2 creature with no mana cost, subtypes or copied morph ability. The original can still pay its real `{5}{G}` turn-up cost and become a 6/7 without changing the copy. Face-up sources and the separately tested transforming-copy path retain their existing behavior.

Twenty focused cases cover both seats and source/creator controllers, paid source morph and later turn-up, copy ownership, queued and resolved JSON replay, turn-up in response, paid face-up casting, copying a copy after the original leaves, and rejection of missing mana or an opposing target without mutation. Supporting seeded units prove that counters, damage, tapped status and temporary modifiers are not copied, that creature-entry observers see the copy, and that the hidden printed entry ability does not trigger. Control changes and removal are explicit unit routes rather than additional paid spells. Turning face up uses the existing special-action API; no new action or save schema is introduced.

Focused verification passed 20 tests / 844 assertions in 0.147 seconds. The adjacent set passed 1,244 tests / 22,998 assertions in 24.143 seconds (182 MiB; 24.537 seconds wall), under a 30-second process-tree cap with 512 MiB, Xdebug off and empty data. Two-file Pint and diff checks passed. Full offline, ledger/inventory and exact-head CI results are recorded separately before merge.

The ledger adds Woolly Loxodon as scoped evidence; historical recognition totals remain unchanged. There are no whole-card certificates. Plain morph is the only new branch: megamorph, disguise/ward, merged/modal/general copying and other copy factories remain unverified. The next separate lead is a complete existing Den Protector megamorph record; it was selected by one name from the existing DTK pool, without parsing or reproducing its paid path.

No environment, UI action, practice policy or persisted schema changes are required; `env.example` remains unchanged. No import, live bot, build, restart or deployment is part of this milestone.
