# Selected-group artifact and permanent burial observers

Marionette Master could miss artifacts buried later in the same selected group when Damnation removed the observer first. Four of eight paid-Damnation cases reproduced the missing abilities before this fix. These cases use its printed power of one and bypass its entry ability; they do not certify Fabricate decisions or modified power after departure.

`Game::moveTo()` now retains the existing selected group's pre-event observers before recording the departing object's death. Same-controller artifact and permanent burial callbacks use each snapshot's battlefield face, original controller and incarnation, along with the selected object's captured definition/current creature status. Once-per-turn marks are shared with surviving original incarnations. The original event-family queue order is preserved. Ordinary single-source burial also retains the source's old incarnation. This reuses `DeathObserverBatch`; no additional saved queue or schema is introduced.

Only actual battlefield-to-graveyard movement dispatches these callbacks. An observer exiled in the same selected group can still see other artifacts that actually reach the graveyard, while exiled artifacts cause no burial event. Tokens reaching the graveyard count even though the engine subsequently represents them as gone. Discarding an artifact, bouncing or directly exiling the source does not become battlefield burial.

[ArtifactGraveyardObserverTest](../tests/Game/ArtifactGraveyardObserverTest.php) pins the complete KLD Marionette Master record, UUID `fb6344e8-3412-57c9-8bca-e9a02708ac15`, normalized-LF SHA-256 `7f7ce7cdddcd200976510eebe22ccead17a0e7eea68ff7c179e990f02f05b335`. Tests use the existing exact 2X2 Damnation fixture, both active seats, both original controllers, both insertion orders, own/opponent artifacts, queued-ability and pre-spell JSON replay. Synthetic controls cover an/another, artifact/permanent/nontoken/type filters, once-per-turn, transformed and face-down observers, source incarnation, exile replacements, token disappearance and discard.

The complete 2XM Disciple of the Vault record, UUID `23ab39a0-1531-586d-b0e6-d47e23a2ba7e`, is separately pinned with SHA-256 `b33eed918ceedab68166974331934d0653d67a4764ae58e672b2b5d34acc0913`. Its entire optional all-player ability is currently unread. A warning regression and the explicit-gap ledger retain that limitation; the same-controller fix does not claim to implement its targeting or optional resolution.

Initial adjacent checks passed 250 cases/3,311 assertions; three changed PHP files passed Pint. Final focused/full-suite and exact-head CI evidence will be recorded before merge.

No parser, schema, environment or Discord UI changes; `env.example` needs no additions. This is scoped callback evidence for Marionette Master, not a whole-card/newest-printing certificate. Source power after departure, counters and continuous effects need their own last-known-state tests; the current fallback reads printed power. General replacement ordering, all-player/optional artifact callbacks, sacrifice-cost choices and APNAP ordering remain separate. Recognition remains 11,282 of 28,729 names, with zero whole-card certificates. No imported-gameplay, bot/Gaia, import, build, deploy or restart actions are performed.
