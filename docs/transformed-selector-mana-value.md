# Mana-value selectors and transformed creatures

Paid cached Culling Sun destroyed a transformed Huntmaster of the Fells even though its front-face mana value is four. The selector read the visible back face's absent mana cost as zero. Mana-value selectors now use the existing `battlefieldManaValue()` helper, which already handles the bounded face-down, transforming and single-face copy shapes. [Wizards' rules notes](https://magic.wizards.com/en/news/feature/eldritch-moon-release-notes-2016-07-08) explain the front-face mana-value rule and the distinction for a single-face copy.

On main `906ba53d9fb4a7dbd95165f55b754adabe627018`, two paid cases reached 26 assertions and failed for both seats. An earlier test setup used insufficient white mana and failed before payment; that was a fixture error, not evidence of a gameplay defect. After the fix, the two expanded cases pass 42 assertions. They restore the paid stack through JSON and include face-up and face-down Huntmaster, a low-value creature, and seeded single-face and transforming token shapes. Transforming Huntmaster and the copy states are seeded, so these tests do not certify those abilities or cards.
