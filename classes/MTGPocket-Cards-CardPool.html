CardPool
in package
  • Application
implements JsonSerializable

CardPool.php : 27

The cards of one set that packs can hold, sorted the way packs are built: by color, then by rarity. Packs are one set plus one color, so each color of a set is its own pool.

Each card appears once, under one color: its own color when it has exactly one, MULTICOLOR when it has several and COLORLESS when it has none (artifacts, most lands).
