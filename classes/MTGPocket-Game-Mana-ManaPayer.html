ManaPayer
in package
  • Application

FinalYes
ManaPayer.php : 28

Pays a cost for the player, the way MTG Arena does: from floating mana first, then by activating mana abilities of untapped permanents (rule 601.2g, which lets a player activate mana abilities while paying).

Colored and colorless symbols are matched to mana first (a bipartite matching, so a dual land is saved for the color only it can make), then generic mana takes what is left. Floating mana and the sources that can make the fewest colors are spent first.
