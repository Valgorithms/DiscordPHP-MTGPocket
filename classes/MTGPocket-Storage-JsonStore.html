JsonStore
in package
  • Application

JsonStore.php : 28

Documents kept as JSON files, one file per document: `{directory}/{collection}/{id}.json`.

Writes go to a temporary file that is renamed over the old one, so a crash never leaves half a document behind. update() holds an exclusive lock on the document for the whole read-modify-write, so two writers (two bot processes, or the bot and the importer) never lose each other's changes.
