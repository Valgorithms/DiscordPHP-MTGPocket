Exporter
in package
  • Application

FinalYes
Exporter.php : 33

Decks and collections as files other programs open:

  • arena: MTG Arena's import text (Commander, Deck and Sideboard sections of N Name (SET) number), which Moxfield and Archidekt also read.
  • frogtown: a plain decklist (N Name, a blank line, then the sideboard), the MTGO text that Frogtown, Cockatrice and Forge import.
  • tts: a Tabletop Simulator saved object, a deck of cards whose faces are Scryfall images, one pile each for the main deck, side deck and commander.
