CardPoolImporter
in package
  • Application

CardPoolImporter.php : 33

Reads card pools out of the MTGJSON build that DiscordPHP-MTG keeps, so the game has its own stable copy of every set it sells packs of.

A set's pool is the cards its real boosters hold: front faces only, no promos and no basic lands, one printing per card name (the lowest collector number, so showcase and borderless variants do not double up). When MTGJSON marks which cards are in the set's default boosters, only those are kept.

Images are not copied: each card keeps its scryfallId, from which DiscordPHP-MTG builds Scryfall image URLs.
